# Roam

Independent fictional portfolio demo. Node 22.23.1 / npm 10.9.8. Use `npm ci`, `npm run dev` (4186), `npm run check`, `npm run test:e2e`. SvelteKit 3 configuration lives in vite.config.ts. GitHub Pages base is /roam-sveltekit; preserve prerendered direct routes and trailing slashes.

Domain rules live in src/lib/domain.ts; fixtures and browser persistence remain separate. Integer cents and date-only trip dates. Do not introduce live travel APIs, bookings, credentials or external data submission. Native accessible controls must provide every reorder and move operation. Update tests and architecture notes for changed validation or persistence behavior. Original code MIT; image provenance in ASSETS.md.
